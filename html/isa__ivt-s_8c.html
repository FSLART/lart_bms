void IVT_CAN_Setup ( CAN_HandleTypeDef *  hcan)

Configures FDCAN filters for IVT-S sensor data and starts the controller.

Sets up individual mask filters to accept only the specific IVT-S CAN IDs for voltage (U1, U2, U3), current, temperature, power, and command acknowledgments. Routes all accepted messages to RX FIFO0, enables the RX FIFO0 interrupt, and starts the FDCAN peripheral.

Parameters
hfdcanPointer to the initialized FDCAN handle (e.g., &hcan1).
Return values
None

◆ IVT_CAN_Setup_AllMessages()

void IVT_CAN_Setup_AllMessages ( CAN_HandleTypeDef *  hcan)

Configures FDCAN to receive all CAN messages by setting wildcard filters.

Installs two mask filters—one for standard IDs (0x000–0x7FF) and one for extended IDs (0x00000000–0x1FFFFFFF)—each with a zero mask so that all IDs pass through. Routes all messages into RX FIFO 0, enables the new-message interrupt, and starts the FDCAN peripheral.

Parameters
hfdcanPointer to the initialized FDCAN handle (e.g., &hcan1).
Return values
None

void IVT_FAULT_CHECK ( void  )

Initiates a fault check by requesting system error status from the IVT-S sensor.

Sends the “Get system errors” command (0x41/0x00) over CAN. An optional measurement-error request (IVT_MEASURERROR_CMD) is commented out.

Note
The response will be handled in HAL_FDCAN_RxFifo0Callback().
Return values
None
