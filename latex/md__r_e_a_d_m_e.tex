\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{📘 Overview}\label{md__r_e_a_d_m_e_autotoc_md1}
This project implements a {\bfseries{Battery Management System (B\+MS)}} using the {\bfseries{Analog Devices A\+D\+B\+M\+S6822}} as the main interface IC and an {\bfseries{S\+T\+M32\+F412\+R\+E\+T6}} microcontroller as the host controller. ~\newline
 The system manages daisy-\/chained {\bfseries{A\+D\+B\+M\+S6830}} devices over {\bfseries{iso\+S\+PI}}, monitors an {\bfseries{I\+V\+T-\/s current/voltage sensor}} via {\bfseries{C\+AN}}, and communicates with a {\bfseries{Node-\/\+R\+ED dashboard}} or other U\+Is through {\bfseries{U\+A\+RT (D\+MA)}} and {\bfseries{Bluetooth}}.

In addition to cell voltage and temperature monitoring, the system integrates\+:
\begin{DoxyItemize}
\item Contactor and precharge control logic
\item P\+I\+D-\/based fan management for temperature regulation
\item R\+TC timestamping and on-\/chip M\+CU temperature sensing
\item E\+E\+P\+R\+O\+M-\/based configuration storage
\item Multi-\/threaded (interrupt-\/driven) timing and open-\/wire diagnostics
\end{DoxyItemize}
